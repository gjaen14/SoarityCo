# Soarity Digital Studio - Design Skills

Este directorio contiene los skills de diseño para el proyecto Soarity Digital Studio.

## Skills Disponibles

| Skill | Descripción |
|-------|-------------|
| **visual-tone-definition** | Define el tono visual general del proyecto |
| **one-page-layout-architecture** | Arquitectura de layouts para páginas one-page |
| **typography-system-editorial** | Sistema tipográfico editorial |
| **color-palette-governance** | Gobernanza de paleta de colores |
| **imagery-and-art-direction** | Dirección de arte e imágenes |
| **brand-symbol-usage** | Uso de símbolos de marca |
| **premium-ui-restraint** | Restricciones de UI premium |

## Uso

Los skills se activan automáticamente cuando Gemini detecta que son relevantes para tu solicitud. También puedes invocarlos explícitamente mencionando el nombre del skill en tu prompt.

## Estructura

Cada skill sigue la estructura estándar:

```
skill-name/
├── SKILL.md        # Instrucciones principales (requerido)
├── references/     # Documentación de referencia (opcional)
└── assets/         # Templates y recursos (opcional)
```
