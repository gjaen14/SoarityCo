# Imagery and Art Direction

## Propósito

Este skill define cómo deben seleccionarse y utilizarse las imágenes dentro
de la web one-page premium. Su función es asegurar que la fotografía y los
recursos visuales refuercen el tono editorial, la sobriedad y la percepción
premium del sitio.

Las imágenes acompañan la narrativa; no compiten con ella.

---

## Cuándo usar este skill

- Después de definir tono visual, estructura y sistema de color
- Antes de aplicar imágenes finales o recursos gráficos
- En todos los proyectos one-page premium con contenido visual

Este skill es obligatorio cuando se utilizan imágenes.

---

## Qué produce este skill

Este skill produce:
- Lineamientos de selección de imágenes
- Criterios de encuadre, iluminación y estilo
- Reglas de coherencia visual
- Límites claros sobre qué tipo de imágenes usar

Este skill NO produce:
- Imágenes específicas
- Recursos gráficos finales
- Ilustraciones personalizadas
- Composición visual detallada

---

## Principios centrales

- La imagen debe transmitir criterio, no espectáculo
- La sobriedad visual comunica profesionalismo
- El contexto importa más que el sujeto
- Lo que no se muestra es tan importante como lo que se muestra

---

## Reglas y restricciones

### Debe

- Priorizar fotografía de estilo editorial
- Utilizar iluminación suave y controlada
- Favorecer encuadres parciales y composiciones naturales
- Mantener coherencia estética en todas las imágenes
- Apoyar la narrativa de tecnología, marketing y branding

### No debe

- Utilizar imágenes genéricas de marketing
- Mostrar escenas forzadas o artificiales
- Abusar de fotografías con sonrisas exageradas o poses comerciales
- Introducir colores estridentes o contrastes agresivos
- Usar ilustraciones caricaturescas o estilos infantiles

---

## Tipos de imágenes recomendadas

El sistema visual debe favorecer:

- Espacios de trabajo reales
- Detalles de manos, objetos o procesos
- Tecnología mostrada de forma discreta
- Personas sin protagonismo explícito del rostro
- Escenas que sugieran acción y enfoque

## Checklist de validación

- [ ] Las imágenes refuerzan el tono editorial y premium
- [ ] No hay uso de imágenes genéricas o comerciales
- [ ] La iluminación y el encuadre son sobrios
- [ ] Las imágenes no compiten con la tipografía
- [ ] La narrativa visual se mantiene coherente
