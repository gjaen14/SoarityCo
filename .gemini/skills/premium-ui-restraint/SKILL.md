# Premium UI Restraint

## Propósito

Este skill define cómo deben comportarse los elementos de interfaz dentro de
la web one-page premium. Su función es asegurar que la UI sea discreta,
funcional y coherente con una experiencia premium, evitando protagonismo
innecesario de botones, animaciones o efectos.

La interfaz acompaña la experiencia, no la domina.

---

## Cuándo usar este skill

- Después de definir estructura, tipografía, color e imágenes
- Antes de implementar interacciones o estados UI
- En todos los proyectos one-page premium sin excepción

Este skill es obligatorio.

---

## Qué produce este skill

Este skill produce:
- Reglas de uso de botones y elementos interactivos
- Límites para animaciones y transiciones
- Criterios de jerarquía en la interfaz
- Lineamientos de comportamiento UI

Este skill NO produce:
- Diseños de componentes específicos
- Animaciones detalladas
- Código de interacción
- Estilos visuales finales

---

## Principios centrales

- Menos interacción genera más elegancia
- La interfaz debe sentirse natural y silenciosa
- La funcionalidad precede al efecto visual
- Cada interacción debe tener un propósito claro

---

## Reglas y restricciones

### Debe

- Utilizar botones simples y claramente identificables
- Mantener animaciones suaves y funcionales
- Priorizar transiciones discretas
- Respetar la jerarquía visual definida
- Favorecer la usabilidad sobre el impacto visual

### No debe

- Introducir animaciones llamativas o innecesarias
- Usar microinteracciones decorativas
- Saturar la interfaz con estados visuales
- Convertir la UI en el foco principal del diseño
- Comprometer el rendimiento por efectos visuales

---

## Elementos UI gobernados por este skill

Este skill regula, entre otros:

- Botones y CTAs
- Navegación sticky
- Estados hover y focus
- Transiciones entre secciones
- Pantallas de carga

Todos deben comportarse de forma discreta y coherente.
