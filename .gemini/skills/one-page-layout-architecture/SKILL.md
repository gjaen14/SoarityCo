# One Page Layout Architecture

## Propósito

Este skill define la estructura base de la web one-page premium.
Su función es establecer la arquitectura narrativa del sitio,
determinando cómo se organiza el contenido a lo largo del scroll
para comunicar valor, autoridad y claridad estratégica.

Este skill asegura que la experiencia sea coherente, fluida
y defendible desde un punto de vista premium.

---

## Cuándo usar este skill

- Después de ejecutar el skill visual-tone-definition
- Antes de definir tipografías, colores o imágenes
- En todos los proyectos de web one-page premium sin excepción

Este skill es obligatorio y forma parte del núcleo del sistema.

---

## Qué produce este skill

Este skill produce:
- Definición del tipo de one-page (editorial, estratégica, premium)
- Orden lógico de las secciones
- Jerarquía de contenido a lo largo del scroll
- Ritmo visual y uso del espacio

Este skill NO produce:
- Layouts visuales finales
- Componentes UI
- Animaciones
- Código HTML o CSS

---

## Principios centrales

- Una página es una narrativa continua, no un conjunto de bloques aislados
- El scroll es el hilo conductor de la experiencia
- La claridad estructural transmite profesionalismo
- El ritmo visual es tan importante como el contenido

---

## Reglas y restricciones

### Debe

- Definir una estructura clara y predecible
- Priorizar un hero a pantalla completa como punto de entrada
- Mantener secciones amplias, respiradas y bien delimitadas
- Guiar al usuario desde la propuesta de valor hasta el contacto
- Adaptarse a negocios de tecnología, marketing y branding

### No debe

- Fragmentar la experiencia en secciones inconexas
- Sobrecargar la página con demasiados bloques
- Alterar el orden narrativo sin justificación estratégica
- Imitar estructuras genéricas de landing pages comerciales

---

## Estructura conceptual recomendada

La arquitectura base de la one-page debe contemplar:

1. Hero a pantalla completa
2. Posicionamiento / propuesta de valor
3. Servicios (tecnología, marketing, branding)
4. Método, enfoque o autoridad
5. Cierre estratégico y contacto

El número de secciones puede variar, pero la narrativa debe mantenerse.
