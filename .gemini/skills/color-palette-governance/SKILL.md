# Color Palette Governance

## Propósito

Este skill define cómo se gobierna el uso del color dentro de la web one-page premium.
Su función es establecer un sistema cromático controlado que refuerce el tono visual,
la jerarquía de contenido y la experiencia premium sin caer en lo decorativo.

El color se utiliza como herramienta de orden y énfasis, no como elemento expresivo libre.

---

## Cuándo usar este skill

- Después de definir el tono visual y el sistema tipográfico
- Antes de aplicar imágenes, UI o estados interactivos
- En todos los proyectos one-page premium sin excepción

Este skill es obligatorio.

---

## Qué produce este skill

Este skill produce:
- Definición de roles de color (base, soporte, acento)
- Reglas de jerarquía cromática
- Límites claros para el uso del color
- Criterios de contraste y legibilidad

Este skill NO produce:
- Códigos hexadecimales específicos
- Gradientes definidos
- Paletas decorativas
- Aplicaciones visuales finales

---

## Principios centrales

- El color estructura, no adorna
- Menos colores generan mayor autoridad visual
- El contraste comunica jerarquía
- La consistencia cromática transmite profesionalismo

---

## Reglas y restricciones

### Debe

- Limitar la paleta a un número reducido de colores
- Asignar un rol claro a cada color
- Priorizar tonos sobrios y controlados
- Mantener alto contraste para legibilidad
- Reforzar el tono editorial y premium definido

### No debe

- Utilizar colores saturados sin justificación
- Introducir gradientes modernos o decorativos
- Cambiar colores entre secciones sin criterio
- Usar el color como elemento principal de impacto
- Romper la coherencia cromática por moda o tendencia

---

## Roles cromáticos definidos

El sistema de color debe contemplar, como mínimo:

- Color base (fondos principales)
- Color de soporte (fondos secundarios o divisiones)
- Color de texto principal
- Color de acento (uso puntual y controlado)
- Estados interactivos (hover, foco, activo)

Cada rol debe tener reglas claras y consistentes.

- [ ] La paleta es limitada y coherente
- [ ] Cada color cumple un rol específico

- [ ] No hay uso decorativo o arbitrario del color
