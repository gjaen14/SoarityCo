# Brand Symbol Usage

## Propósito

Este skill define cómo deben utilizarse los símbolos de marca dentro de la
web one-page premium. Su función es asegurar que el logo y otros elementos
identitarios acompañen la experiencia sin dominarla ni convertirse en
elementos decorativos excesivos.

La marca se presenta con seguridad, no con insistencia.

---

## Cuándo usar este skill

- Después de definir la arquitectura de la página
- Antes de aplicar el logo o elementos de identidad visual
- En todos los proyectos one-page premium con marca definida

Este skill es obligatorio cuando existe un sistema de marca.

---

## Qué produce este skill

Este skill produce:
- Reglas de uso del logo y símbolos de marca
- Criterios de jerarquía visual
- Límites de repetición y protagonismo
- Lineamientos de integración con el layout

Este skill NO produce:
- Versiones finales del logo
- Adaptaciones gráficas del símbolo
- Aplicaciones visuales específicas
- Recursos de branding finales

---

## Principios centrales

- La marca no necesita repetirse para ser reconocida
- El espacio alrededor del símbolo es parte del diseño
- La contención comunica seguridad
- El símbolo acompaña, no lidera la narrativa

---

## Reglas y restricciones

### Debe

- Usar el símbolo de marca de forma puntual y estratégica
- Mantener amplio espacio de respiro alrededor del logo
- Respetar la jerarquía visual del contenido
- Adaptar el símbolo al contexto sin alterar su integridad
- Priorizar versiones limpias y sobrias del logo

### No debe

- Repetir el logo innecesariamente
- Usar el símbolo como elemento decorativo
- Forzar protagonismo visual del branding
- Alterar proporciones, colores o formas del símbolo
- Integrar el logo en fondos que comprometan su legibilidad

---

## Contextos de uso recomendados

El símbolo de marca debe aparecer, como mínimo, en:

- Hero principal
- Navegación (de forma discreta)
- Cierre o footer

Fuera de estos contextos, su uso debe estar justificado.

- [ ] El branding no domina la experiencia

- [ ] No hay uso decorativo del símbolo
