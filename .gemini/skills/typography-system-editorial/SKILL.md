# Typography System Editorial

## Propósito

Este skill define el sistema tipográfico de la web one-page premium.
Su función es establecer cómo se utiliza la tipografía para comunicar
jerarquía, claridad y carácter editorial, alineado a un tono premium,
sobrio y estratégico.

La tipografía actúa como principal herramienta de comunicación,
no como elemento decorativo.

---

## Cuándo usar este skill

- Después de definir el tono visual general
- Una vez establecida la arquitectura de la one-page
- Antes de definir colores, imágenes o componentes UI

Este skill es obligatorio en proyectos con enfoque editorial o premium.

---

## Qué produce este skill

Este skill produce:
- Definición de roles tipográficos (titulares, cuerpo, apoyo)
- Jerarquías claras de texto
- Reglas de uso y consistencia tipográfica
- Criterios de legibilidad y ritmo

Este skill NO produce:
- Nombres específicos de tipografías
- Tamaños finales en píxeles
- Estilos CSS
- Decisiones de color aplicadas al texto

---

## Principios centrales

- La tipografía comunica autoridad y criterio
- Menos variaciones generan mayor coherencia
- El espacio entre líneas y bloques es parte del diseño
- El texto debe respirar para transmitir lujo y claridad

---

## Reglas y restricciones

### Debe

- Limitar el sistema a un máximo de dos familias tipográficas
- Asignar un rol claro a cada tipo de texto
- Priorizar titulares con carácter editorial
- Mantener cuerpos de texto limpios y altamente legibles
- Usar jerarquía tipográfica para guiar la lectura

### No debe

- Utilizar múltiples tipografías sin justificación
- Mezclar estilos tipográficos incompatibles
- Abusar de pesos extremos o contrastes innecesarios
- Convertir la tipografía en un elemento decorativo
- Sacrificar legibilidad por estilo

---

## Roles tipográficos definidos

El sistema debe contemplar, como mínimo:

- Titulares principales (hero y secciones)
- Subtítulos o textos de apoyo
- Cuerpo de texto
- Microcopy (botones, navegación, notas)

Cada rol debe tener reglas claras y consistentes.
