# Visual Tone Definition

## Propósito

Este skill define el tono visual general de la web one-page premium.
Su función es traducir el moodboard en un conjunto de reglas estéticas
claras que guíen todas las decisiones visuales posteriores.

Este skill establece el “clima visual” del proyecto y actúa como
marco de referencia para tipografía, color, imágenes e interacción.

---

## Cuándo usar este skill

- Siempre al inicio de un proyecto one-page premium
- Inmediatamente después de recibir y analizar el moodboard
- Antes de activar cualquier otro skill visual o estructural

Este skill es obligatorio y debe ejecutarse primero.

---

## Qué produce este skill

Este skill produce:
- Definición del tono visual (editorial, premium, sobrio, estratégico)
- Rasgos de personalidad visual de la marca
- Límites estéticos claros

Este skill NO produce:
- Colores específicos
- Tipografías concretas
- Componentes UI
- Diseños finales o renders

---

## Principios centrales

- El lujo se comunica desde la contención, no desde el exceso
- El silencio visual es una herramienta de diseño
- La seguridad visual reemplaza la necesidad de explicar demasiado
- Menos elementos, mayor intención

---

## Reglas y restricciones

### Debe

- Respetar estrictamente el moodboard
- Favorecer composiciones limpias y equilibradas
- Utilizar espacio negativo como parte del diseño
- Transmitir sobriedad y criterio estratégico
- Mantener una estética editorial y profesional

### No debe

- Usar colores saturados
- Aplicar gradientes modernos o decorativos
- Introducir efectos visuales llamativos o innecesarios
- Utilizar ilustraciones caricaturescas o estilos infantiles
- Agregar elementos solo por impacto visual
